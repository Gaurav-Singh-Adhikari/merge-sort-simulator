# Merge Sort Simulator — DAA CIA 3(b)

An interactive browser-based Merge Sort prototype for demonstrating the working of the algorithm.

## Features
- Custom integer array input
- Random array generation
- Step-by-step execution
- Auto Play / Pause
- Adjustable animation speed
- Visual split, comparison, and merge stages
- Operation trace
- Comparison counter
- Time and space complexity display
- Responsive interface

## Run
Open `index.html` in a modern web browser. No installation or server is required.

## Algorithm
Merge Sort uses divide and conquer:
1. Divide the array into two halves.
2. Recursively divide until single-element subarrays remain.
3. Compare elements from adjacent sorted portions.
4. Merge the portions in ascending order.
5. Continue until the entire array is sorted.

Time Complexity: O(n log n)
Space Complexity: O(n)
